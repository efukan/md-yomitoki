最初の公開版です。

**MDよみとき**は、AI に書かせている Markdown を横に開いておき、どこが変わったかをすぐに確かめられる Mac のアプリです。

Claude Code などの AI エージェントに資料や仕様書を書かせていると、「今どこを書き換えたのか」が分かりにくくなりがちです。MDよみときで開いておけば、ファイルが書き換わるたびに表示が追いかけて、変わったところに印が付きます。

### できること

**変わったところが、すぐ分かる**

- ファイルが書き換わると自動で読み直し、変わった段落の横にオレンジの線を付けます。
- 消えた行には赤い印を付けます。マウスを載せると、変更前の文が見られます。
- ⌘J を押すたびに、次の変更箇所へ移動します。
- 読み終えたら「確認済みにする」を押します。印が消えて、次からはそれ以降の変更だけに印が付きます。

**日本語の文書が読みやすい**

- 表・チェックリスト・コード・図（Mermaid）を、GitHub と同じように表示します。
- `**「重要」**` のように、ほかのアプリでは崩れがちな日本語の太字も、正しく太字にします。

**探しやすく、その場で直せる**

- ひらがなとカタカナ、全角と半角の違いを気にせずに検索できます。
- ⌘E で編集の画面に切り替えて、その場で直して保存できます。

**いつもの Mac と同じ感覚で使える**

- タブ、ダークモード、トラックパッドのスワイプでの「戻る」など、ほかの Mac のアプリと同じように使えます。

ほかの機能は [README](https://github.com/efukan/md-yomitoki#readme) で紹介しています。

### 動作環境

macOS 15 Sequoia 以降（Apple シリコン・Intel）

### インストール

1. このページの下にある **Assets** の `MDYomitoki.dmg` をクリックして、ダウンロードします。
2. ダウンロードした dmg を開き、「MDよみとき」のアイコンを「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダから「MDよみとき」を開きます。

新しい版が出ると、アプリの中でお知らせします。
